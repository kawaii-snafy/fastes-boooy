# Орда 22–60 — общая библиотека `FastesBoooy_Horde`

Модуль: [`addons/FastesBoooy_Horde/`](../../addons/FastesBoooy_Horde/) (TOC `## X-FastesBoooy-Module: library`,
генерируемый `Data.lua`, 12 сегментов в `Segments/`). Клиент — World of Warcraft: Forever 1.60.1.70862
(`## Interface: 16001`). Все координаты — `{uiMapID, x, y}` Forever из снимка `tools/data/forever_db.lua`.

## 1. Обзор

Это **не отдельный гайд**, а общий квестовый маршрут Орды 22–60 без классовых шагов. Модули классов
подключают его так (см. `docs/ROUTE_FORMAT.md`, «Общие сегменты и вставки»):

```lua
FastesBoooy.UseSegments("horde-undead-paladin", { "h-22-hillsbrad", "h-24-barrens-stonetalon", ...,
    "h-56-felwood-winterspring-plaguelands" })
FastesBoooy.AddInsert("horde-undead-paladin", { after = "h-27-tb-arrive", steps = { ... обучение 26 ... } })
```

Библиотека рассчитана на оба профиля Орды: нежить-паладин (`Scourge PALADIN`) и Skyborne-друид
(`Skyborne DRUID`). Все квесты доступны обоим; где 1–22-маршруты различаются, шаг ограничен фильтром расы
(см. §8). Обучения классу в библиотеке нет — это вставки модулей классов по якорям (§10).

Маршрут: Громовой Утёс → Оргриммар → Подгород → Предгорья Хилсбрада → Степи и Когтистые горы → Ясеневый
лес, Небесное плато, Тысяча Игл → Хилсбрад, Альтеракские горы, Нагорье Арати → Тернистая долина →
Пустоши и Пылевые топи → Нагорье Арати и Бесплодные земли → Болото Печали и Тернистая долина → Танарис и
Фералас → Внутренние земли, Тлеющее ущелье, Пылающие степи, Выжженные земли → Азшара, кратер Ун'Горо,
Силитус → Оскверненный лес, Зимние Ключи, Западные и Восточные Чумные земли (60 в Часовне Последней
Надежды).

гейте, а попутные убийства его сокращают.

* Полный прогон 12 сегментов из реальных состояний 22 для обоих профилей; швы цепочек h-31 → h-34 и
  h-44 → h-46 (место, журнал, камень, точки полёта, уровень) сходятся: 0 ERROR, уровень входа каждого
  сегмента не ниже планового.
* Найдены и исправлены три места, где движок пропустил бы шаги («якорь вперёд»: необязательный шаг
  `complete` после фоновой цели, выполненной раньше, делает шаг выполненным и проматывает транзитные и
  необязательные шаги перед ним):
  * h-24: отдельный `complete 6393` во второй петле долины гарпий проматывал необязательные сдачи 86576 /
    6284 и весь блок Непроглядной Пучины → объединён с `complete 6381`;
  * h-53: отдельный `complete 4300` проматывал шаг точки полёта Укрытия Маршалла (в симуляторе точка не
    изучалась) → объединён с `complete 4291`;
  * h-22: гейт `{ complete = 546, level = … }` мог промотать необязательную сдачу 98094 → гейт теперь
    `complete = { 529, 546 }`.
* `h-41-hammerfall-arrive`: радиус 60 → 25, чтобы шаг с заметкой о пропущенных элитных квестах не
  засчитывался сразу при посадке.
* 33 шага-сдачи без заметки получили короткие двуязычные заметки (имена NPC из подсказок Wowhead Forever
  ruRU); английские названия в русских заметках заменены (Мрачная вершина, Скальное гнездовье, застава
  Белого Плеса, огненная агава); устаревшие упоминания 592 в заголовках убраны; `WARN-OK` — на первой строке
  каждого шага с WARN.
