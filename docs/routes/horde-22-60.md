Модуль: [`addons/FastesBoooy_Horde/`](../../addons/FastesBoooy_Horde/) (TOC `## X-FastesBoooy-Module: library`,
генерируемый `Data.lua`, 12 сегментов в `Segments/`). Клиент — World of Warcraft: Forever 1.60.1.70862
(`## Interface: 16001`). Все координаты — `{uiMapID, x, y}` Forever из снимка `tools/data/forever_db.lua`.

## 1. Обзор

Это **не отдельный гайд**, а общий квестовый маршрут Орды 22–60 без классовых шагов. Модули классов
подключают его так (см. `docs/ROUTE_FORMAT.md`, «Общие сегменты и вставки»):

```lua
FastesBoooy.UseSegments("horde-undead-paladin", { "h-22-hillsbrad", "h-24-barrens-stonetalon", ...,
    "h-56-felwood-winterspring-plaguelands" })
FastesBoooy.AddInsert("horde-undead-paladin", { after = "h-27-tb-arrive", steps = { ... обучение 26 ... } })
```

Библиотека рассчитана на оба профиля Орды: нежить-паладин (`Scourge PALADIN`) и Skyborne-друид
(`Skyborne DRUID`). Все квесты доступны обоим; где 1–22-маршруты различаются, шаг ограничен фильтром расы
(см. §8). Обучения классу в библиотеке нет — это вставки модулей классов по якорям (§10).

Маршрут: Громовой Утёс → Оргриммар → Подгород → Предгорья Хилсбрада → Степи и Когтистые горы → Ясеневый
лес, Небесное плато, Тысяча Игл → Хилсбрад, Альтеракские горы, Нагорье Арати → Тернистая долина →
Пустоши и Пылевые топи → Альтерак, Нагорье Арати и Бесплодные земли → Болото Печали и Тернистая долина →
Танарис и Фералас → Внутренние земли, Тлеющее ущелье, Пылающие степи, Выжженные земли → Азшара, кратер
Ун'Горо, Силитус → Оскверненный лес, Зимние Ключи, Западные и Восточные Чумные земли (60 в Часовне
Последней Надежды).

убийства, rested-бонус и еду. Обязательные гейты проверяют **настоящий** уровень в игре: кто пропустил
необязательное, добирает на гейте, а попутные убийства его сокращают.
