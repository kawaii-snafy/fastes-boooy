# Adventure Atlas — атлас приключений для World of Warcraft: Forever

Аддон для **World of Warcraft: Forever** (клиент 1.60.1, `## Interface: 16001`): путеводитель по миру игры.
Сейчас в нём гайды быстрой прокачки 1–60: аддон ведёт по маршруту шаг за шагом, показывает текущий шаг и стрелку
к цели, сам берёт и сдаёт квесты маршрута, сам отслеживает прогресс. Гайд выбирается автоматически по расе и классу
персонажа. Окно атласа открывается кнопкой на миникарте: «Твоё приключение» (маршрут и его главы) и «База знаний»
(в работе).

Аддон — это **две папки**:

| Папка | Что это |
|---|---|
| `AdventureAtlas` | ядро: движок маршрутов, автоматизация квестов, стрелка, окно шагов, настройки |
| `AdventureAtlas_Guides` | все гайды: по одному на каждую расу и класс, уровни 1–60 |

## Гайды

Каждый гайд — для одной расы и одного класса. Стартовую зону раса проходит по-своему, с 12-го уровня все
идут одним путём (Серебряный бор, Степи, Когтистые горы, Ясеневый лес, дальше до 60-го); шаги своего класса
(тренеры, классовые задания, верховая езда) и своей расы вставляются в этот путь.

**Все 28 гайдов (уровни 1–60), у каждого — шаги своего класса и своей расы:**

| Раса (стартовая зона) | Гайд | id (`/aa route <id>`) |
|---|---|---|
| Орк (Дуротар) | Орк-охотник, Орк-маг, Орк-разбойник, Орк-шаман, Орк-чернокнижник, Орк-воин | `orc-hunter`, `orc-mage`, `orc-rogue`, `orc-shaman`, `orc-warlock`, `orc-warrior` |
| Тролль (Дуротар) | Тролль-охотник, Тролль-маг, Тролль-жрец, Тролль-разбойник, Тролль-шаман, Тролль-чернокнижник, Тролль-воин | `troll-hunter`, `troll-mage`, `troll-priest`, `troll-rogue`, `troll-shaman`, `troll-warlock`, `troll-warrior` |
| Таурен (Мулгор) | Таурен-друид, Таурен-охотник, Таурен-шаман, Таурен-воин | `tauren-druid`, `tauren-hunter`, `tauren-shaman`, `tauren-warrior` |
| Нежить (Тирисфальские леса) | Нежить-маг, Нежить-паладин, Нежить-жрец, Нежить-разбойник, Нежить-чернокнижник, Нежить-воин | `undead-mage`, `undead-paladin`, `undead-priest`, `undead-rogue`, `undead-warlock`, `undead-warrior` |
| Скайборн (остров Зефрас) | Скайборн-друид, Скайборн-охотник, Скайборн-разбойник, Скайборн-шаман, Скайборн-воин | `skyborne-druid`, `skyborne-hunter`, `skyborne-rogue`, `skyborne-shaman`, `skyborne-warrior` |

Гайд выбирается сам по расе и классу персонажа; `/aa routes` показывает подходящие, `/aa route <id>` выбирает
вручную. Шаги класса — это визиты к тренеру на чётных уровнях (там, где путь проходит мимо тренера), классовые
задания (питомцы охотника и чернокнижника, тотемы шамана, стойки воина, формы друида, цепочки паладина нежити и
т. п.), оружейные навыки; шаги расы — расовые задания и верховая езда на 40-м. Что именно делает каждый класс и
где — в [docs/routes/](docs/routes/) (`class-<класс>.md`).

Все 28 гайдов доходят до 60-го уровня в офлайн-проверке (валидатор и прогон через движок): около 4 850–4 980
убийств гринда за весь путь, если делать и необязательные шаги, и до ~6 230 без них; почти весь гринд — на 22–60.

## Установка

1. Скопируйте **обе папки** из `addons/` — `AdventureAtlas` и `AdventureAtlas_Guides` — в
   `World of Warcraft/_forever_/Interface/AddOns/`
   (Battle.net → шестерёнка → «Показать в проводнике» → `_forever_`; у беты папка была `_classic_beta_`).
   Версии папок должны совпадать (сейчас 0.5.0): без ядра гайды не загрузятся, без `AdventureAtlas_Guides` ядру
   нечего показывать. Готовые zip-архивы собирает `make package` (в `dist/`: `AdventureAtlas-*.zip` и
   `AdventureAtlas_Guides-*.zip`).
2. На экране выбора персонажа включите аддоны («AddOns»).
3. В игре: окно гайда появится автоматически. `/aa` выводит список команд.

### Обновление с FastesBoooy

До версии 0.5 аддон назывался FastesBoooy (папки `FastesBoooy` и `FastesBoooy_Guides`, команда `/fb`).

1. **Удалите** из `Interface/AddOns` старые папки `FastesBoooy` и `FastesBoooy_Guides`, а если остались с версии 0.3 —
   ещё и `FastesBoooy_Horde`, `FastesBoooy_UndeadPaladin`, `FastesBoooy_SkyborneDruid`.
2. Скопируйте новые папки `AdventureAtlas` и `AdventureAtlas_Guides` (см. выше).

Если старые папки остались включены, при входе в игру аддон напишет в чат, какие удалить: старое ядро работает
параллельно с новым — второе окно гайда и вторая автоматика квестов.

Сохранённые данные игра хранит по имени папки, поэтому **настройки FastesBoooy не переносятся**: окна, автоматика,
задержка и синхронизация по уровню вернутся к значениям по умолчанию, а выбранный вручную гайд нужно выбрать снова
(`/aa route <id>`). Место в маршруте гайд найдёт сам по сданным квестам, журналу и уровню; если встал не туда —
`/aa sync` (перейти к участку по уровню). Прежние id гайдов версии 0.3 (`horde-undead-paladin`,
`horde-skyborne-druid`) по-прежнему принимаются.

Команды теперь `/aa` или `/atlas` вместо `/fb`.

## Команды

`/atlas` — то же, что `/aa`.

| Команда | Действие |
|---|---|
| `/aa atlas` | открыть / закрыть окно атласа |
| `/aa minimap` | показать / скрыть кнопку на миникарте |
| `/aa show` / `/aa hide` | показать / скрыть гайд |
| `/aa lock` / `/aa unlock` | закрепить / открепить окна |
| `/aa resetpos` | вернуть окно гайда, стрелку и окно атласа на места по умолчанию |
| `/aa back` / `/aa forward` | то же, что кнопки «Назад» / «Вперёд» в окне гайда |
| `/aa next` / `/aa skip` | отметить шаг выполненным / пропущенным |
| `/aa sync` / `/aa sync undo` | перейти к участку маршрута по вашему уровню / вернуть как было |
| `/aa routes`, `/aa route <id>` | список маршрутов / выбрать маршрут |
| `/aa reset` | сбросить прогресс персонажа |
| `/aa config` | настройки (также в меню «Настройки → AddOns») |
| `/aa delay [сек [добавка]]` | пауза автоматики перед каждым действием: `/aa delay` — показать, `/aa delay 1 0.5` — 1 с + случайно до 0,5 с, `/aa delay 0` — мгновенно |
| `/aa status` | текущее состояние |
| `/aa xp [chat\|clear]` | записанный в игре опыт за квесты (см. «Ограничения») |

### Окно атласа

Открывается кнопкой на миникарте (левый клик; правый — настройки; кнопку можно перетащить по краю
миникарты), командой `/aa atlas` или кнопкой «Открыть атлас» в настройках. Вкладки:

* **Твоё приключение** — маршрут персонажа: уровень, сколько шагов пройдено, и главы маршрута (участки) с
  уровнями и прогрессом; текущая глава отмечена `>` и золотым цветом, пройденные — `+` и серым. Кнопка
  «Показать / Скрыть гайд» — то же, что `/aa show` / `/aa hide`.
* **База знаний** — скоро: список квестов с поиском и фильтрами.

Кнопку на миникарте прячет `/aa minimap` или настройка «Кнопка на миникарте». Окно атласа закрывается
крестиком, кнопкой на миникарте или `/aa atlas` (клавиша Esc его пока не закрывает).

### Окно гайда

Сверху — маршрут, уровень, участок и номер шага, сразу под ними три кнопки. Кнопки закреплены
у верхнего края: окно растёт и сжимается только вниз, когда меняется текст шага, и кнопки не
«прыгают». Ниже — текущий шаг, «Попутно» (фоновые цели) и «Далее» — следующие **невыполненные**
шаги (уже сделанное там не показывается).

* **Назад** — показать предыдущий шаг. Если он был пропущен или отмечен вручную, отметка снимается.
* **Вперёд** — шаг выполнен или вы не хотите его делать: перейти к следующему. Если вы смотрите
  прошлый шаг (после «Назад»), кнопка просто возвращает вперёд, ничего не отмечая.
* **Настройки** — то же, что `/aa config`.

Обычно нажимать ничего не нужно: шаги закрываются сами, как только игра сообщает о выполнении.

### Синхронизация по уровню и серые квесты

Если вы прокачались в другом месте и переросли участок маршрута, на котором остановились,
окно гайда предложит: «Вы 23 ур. — участок «13-15 Серебряный бор» пройден по уровню. Перейти к …?»
с кнопками **Перейти** и **Остаться**. Участок считается пройденным, когда ваш уровень не ниже его
верхней границы плюс запас (по умолчанию 2). Переход предлагается, только если он что-то
экономит — на пропускаемом отрезке есть новые квесты, которых у вас нет; доделать свои квесты,
сдать готовые и навестить тренера в конце участка гайд даёт без вопроса.

После перехода шаги до нового места считаются выполненными, кроме того, что ещё нужно:

* квесты в журнале, которые маршрут сдаёт дальше, — их выполнение остаётся в списке «Попутно»;
  готовые к сдаче квесты пропущенного отрезка — «Сдать» там же;
* последний пропущенный визит к классовому тренеру, а также пропущенные точки полёта и привязка
  камня возвращения, если они нужны следующим шагам, — тоже «Попутно», пока не сделаны (или пока
  маршрут сам не дойдёт до следующего тренера / нужного полёта). Шаг «Лететь» / «Камень
  возвращения» подсказывает, если точка полёта ещё не открыта или камень привязан в другом месте;
* остальные квесты пропущенного отрезка, оставшиеся в журнале, гайд перечисляет в чате — выполните
  их сами или отмените.

Передумали — ссылка **Вернуть** в окне (около 30 секунд) или `/aa sync undo`.
«Остаться» — вопрос повторится на следующем уровне. `/aa sync` переходит по запросу в любом режиме.
В настройках («Синхронизация по уровню»): предлагать переход, переходить автоматически
(с сообщением в чат) или выключить; запас уровней 0–5.

**Пропускать серые квесты** (включено по умолчанию): на участках маршрута, которые вы переросли,
серые для вас квесты (почти без опыта) гайд не предлагает брать и не берёт автоматически — их шаги
считаются выполненными; на участке вашего уровня серый квест, который маршрут берёт нарочно,
остаётся. Квесты, открывающие ещё полезные квесты маршрута, сохраняются. Возьмёте серый квест
сами — его шаги вернутся. Предметы для квестов, которые вы не брали, гайд тоже не собирает.

### Автоматика

Своей кнопки для предметов квестов у аддона нет: используйте кнопку предмета, которую интерфейс
игры показывает у квеста в списке отслеживаемых заданий.

Если решили отказаться от квеста (истёк таймер, элита не по силам, не выпал предмет), просто
бросьте его в журнале — нажимать «Вперёд» не нужно, порядок не важен. Гайд сам пропустит
оставшиеся шаги этого квеста, не вернётся к шагу, где его берут, и напишет об этом в чат.
Передумали — «Назад» (`/aa back`) сразу после сообщения или снова возьмите квест: его шаги вернутся.

Если зажать **Shift** при открытии диалога с NPC, автоматика на этот диалог отключится.
Автоматически аддон берёт только квесты из ближайших шагов маршрута, а сдаёт
только квесты, которые есть в маршруте. Если наград несколько и в маршруте не указано,
какую брать, выбор остаётся за вами.

Автоматика действует не мгновенно, а с небольшой «человеческой» паузой: по умолчанию
0,5 с + случайно до 0,3 с перед каждым принятием, сдачей, выбором награды или реплики
(настройки «Задержка автоматики» и «Случайная добавка», 0–3 с и 0–1 с, или `/aa delay`;
0 — мгновенно, как в других аддонах). Пока идёт пауза, окно можно закрыть или нажать
**Shift** — действие отменится (Shift — до конца диалога с этим NPC); если за это время
окно сменилось, аддон ничего не делает.

## Проверка без игры

```sh
sudo apt-get install lua5.1 lua-check lua-busted   # или luarocks: luacheck, busted
make check      # lint + test + validate + simulate
```

| Цель | Что проверяет |
|---|---|
| `make lint` | luacheck со стандартом `forever`. Он собран из полного списка API клиента Forever (`tools/data/forever_api.lua`), поэтому вызов несуществующей в Forever функции, поля `C_*` или `Enum` — ошибка |
| `make test` | busted-спеки ядра, валидатора и строгого мока клиента. Мок разрешает только функции, события, шаблоны и методы виджетов, которые реально есть в Forever |
| `make validate` | валидатор маршрутов по снимку БД Forever (`tools/data/forever_db.lua`); ни одного непринятого предупреждения, 60-й уровень в конце и бюджет гринда на 1–22. Проверяет: квест существует в Forever и доступен расе, классу и фракции; уровень (по симуляции опыта); цепочки и взаимоисключения; кто выдаёт и принимает квест; расстояние от точки до NPC; тренеров, полётчиков и трактирщиков; журнал на 40 квестов; квесты профессий в обязательных шагах; шаг `complete` у триггера области; визиты к тренеру/торговцу, которые перемотает автопринятие квеста того же NPC |
| `make simulate` | прогон каждого маршрута через настоящий движок на моке: каждый шаг должен завершаться ровно тем действием, которое он требует, включая автопринятие и автосдачу |
| `make report` | перегенерировать `docs/VALIDATION.md` |

CI (`.github/workflows/ci.yml`) запускает `make check` на каждый push и проверяет, что `Data.lua` модуля гайдов
и `docs/VALIDATION.md` актуальны (после изменения маршрутов: `make routedata` и `make report`).

## Чем Forever отличается от Classic (и почему понадобилась валидация)

* Современный API (`C_QuestLog`, `C_GossipInfo`, `C_Map`, `C_Item`, …): многих функций Classic
  (`GetQuestLogTitle`, `GetItemCount`, `IsQuestFlaggedCompleted`, …) в клиенте нет.
* Новая раса Скайборн (raceFile `Skyborne`, у Орды raceID 96) со стартовой зоной Zephras Isle
  (uiMap 2521) и отплытием в Mulgore. Новая комбинация Нежить-паладин со своей цепочкой классовых
  квестов и тренерами (Deathknell, Brill, Bandarion Keep, Undercity, Thunder Bluff).
* Около 750 новых квестов, изменённые уровни. Геометрия карты Mulgore изменена:
  координаты из Classic там неверны. Журнал квестов на 40. Cat Form друида — через цепочку в Moonglade.
* Таблица опыта по уровням и штраф за «серые» квесты — как в Classic. Зелёные мобы дают меньше опыта.

## Ограничения (честно)

* **Аддон работает в живом клиенте Forever, но систематически проверен только офлайн**:
  статический анализ по списку API билда Forever, тесты на строгом моке клиента, валидация
  маршрутов по базе Forever и симуляция прохождения.
  Что подтверждается только в игре, перечислено в конце [docs/VALIDATION.md](docs/VALIDATION.md)
  (раздел «Что подтверждается только в игре»). Например, срабатывает ли автопринятие квестов
  без аппаратного события.
* **Опыт за новые квесты Forever офлайн неизвестен**: ни в одном доступном источнике его нет.
  Валидатор его оценивает, а аддон записывает реальный опыт при сдаче квеста.
  Команда `/aa xp` выводит эти данные, по ним можно уточнить маршруты.
* Данные БД — снимок на 2026-11-07, билд 1.60.1.70862.

### Что ещё не проверено в игре

Гайды собраны по базе Forever и проверены офлайн; в живом клиенте целиком ни один из 28 не пройден. Известные
открытые вопросы (полный список шагов с пометкой `-- CONFIRM` — [docs/routes/confirm-in-game.md](docs/routes/confirm-in-game.md),
решения по умолчанию — `docs/dev/PLAN.md`, раздел E):

* **Опыт за новые квесты Forever** оценён (в каждом маршруте 62–125 таких квестов, 4,5–6,3 % опыта за квесты). Если реальный опыт меньше,
  гейты уровня попросят немного догриндить — маршрут не ломается. Помогите уточнить: `/aa xp`.
* **Полёты на 12–13-м**: скайборны летят из Громового Утёса в Оргриммар (точка полёта считается известной с
  начала); таурены идут туда пешком через Перекрёсток. Если у скайборна полёта нет — идите пешком, как таурены.
* **Тренеры паладина нежити** в Подгороде и Громовом Утёсе есть в базе, но не подтверждены; запасной тренер —
  в Брилле (заметки шагов это называют).
* **Таймер квеста 812** (Дуротар) против городской петли в Оргриммаре; если таймер короче — сдайте противоядие
  сразу после Кор'гана (заметка шага).
* **Классовые детали**: что именно дают некоторые классовые задания в Forever (стойка воина за 94003, задания
  жреца 5658 / 5642 / 5644), цепочка Демона Бездны для тролля-чернокнижника (в базе она только для орков),
  первая цепочка тотема Земли шамана (в базе ошибка предпосылки), уровни заклинаний вне ключевых — по
  оригинальной игре; индексы наград классовых заданий в базе неизвестны (таблица наград есть только у друида),
  поэтому у остальных классов награду выбираете вы (заметки многих шагов советуют предмет).
* **Верховая езда на 40-м**: цена и выдаётся ли маунт вместе с навыком — шаги необязательные, заметки дают оба
  варианта.
* **Русские имена NPC и мест** в заметках частично — собственная транскрипция, а не имена клиента ruRU.
* Квест 98389 в Похоронном звоне (у тренера паладинов) — даётся ли он всем классам; шаги необязательные.
